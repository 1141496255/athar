# أثر — Athar

**يفهمه.. نيابةً عنه.** تطبيق يساند مريض الزهايمر وأسرته، ويفهم احتياج المريض نيابةً عنه.

## المزايا
- **معرفة الأسرة محفوظة:** الروتين، كيف يعبّر عن كل حاجة، وش يطمّنه، السجل الصحي، الأماكن اللي يحنّ لها.
- **يفهم وش يحتاج:** تختار السلوك اللي تشوفه، وأثر يربطه بروتينه وآخر مرة شرب أو دخل الحمام، ويرجّح الحاجة مع الأسباب.
- **يتعلّم:** المرافق يأكد وش كانت الحاجة فعلًا، فتتحدّث أوزان الفهم الخاصة بالمريض.
- **تنبيهات قبل الضيق:** مثل «صار له ٣ ساعات ما شرب»، ووقت الصلاة، ووقت المغرب.
- **لو طلع من البيت:** تنبيه مع اهتزاز وموقع، ويقترح ليش طلع ووين رايح غالبًا، وإرشاد صوتي هادي.
- **وضع الاستلام:** دليل كامل لأي مرافق جديد، وتقدر تشاركه.
- **الساعة (المرحلة الجاية):** معاينة لتجربة الساعة.

## التشغيل
تطبيق ويب تقدر تثبّته على الجوال (PWA)، ما يحتاج بناء:
```
python -m http.server 5173
```
بعدها افتح `http://localhost:5173`. على الجوال: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية».

البيانات محفوظة على الجهاز نفسه (localStorage).

## الهيكل
```
index.html             الواجهة الرئيسية + شاشة البداية
css/style.css          نظام التصميم والأنماط
js/app.js              منطق التطبيق والشاشات ومحرّك الفهم
sw.js                  يخلي التطبيق يشتغل بدون إنترنت
manifest.webmanifest   بيانات التثبيت
assets/                الشعار والأيقونات
```
